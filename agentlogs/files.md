# Files

## Root

### AGENTS.md
- Purpose: Defines mandatory operating rules and logging standards for AI agents working on this project.
- How it works: Instructs agents to maintain living documentation in `agentlogs/` (`architecture.md`, `files.md`, `changelog.md`). Outlines exact formats, update triggers, and consistency rules for every development task.
- Uses: None
- Used by: Development agents and contributors
- Gotchas: Updates to `agentlogs/` are required at the conclusion of every single task before completion.

### app.json
- Purpose: Configuration manifest for the Expo app runtime, builds, and plugins.
- How it works: Sets the app name, slug, orientation, splash screen image and colors, scheme, and plugins (`expo-router`, `expo-splash-screen`). Also enables experimental compiler flags (`typedRoutes`, `reactCompiler`).
- Uses: None
- Used by: Expo CLI, Metro bundler, EAS Build

### babel.config.js
- Purpose: Babel configuration file for transpiling React Native and NativeWind code.
- How it works: Loads the `babel-preset-expo` preset with `nativewind` JSX import source and applies the `nativewind/babel` plugin to parse Tailwind classes.
- Uses: `babel-preset-expo`, `nativewind`
- Used by: Babel during Metro bundling

### expo-env.d.ts
- Purpose: TypeScript environment declarations for Expo project types.
- How it works: References `expo/types` to enable type-safe routing and global Expo variables.
- Uses: `expo/types`
- Used by: TypeScript compiler via `tsconfig.json`
- Gotchas: Auto-generated by Expo; should not be edited manually.

### global.css
- Purpose: Global stylesheet declaring Tailwind directives for NativeWind.
- How it works: Imports `@tailwind base;`, `@tailwind components;`, and `@tailwind utilities;` to inject Tailwind rules into NativeWind.
- Uses: `tailwindcss`, `nativewind`
- Used by: `metro.config.js`, `src/app/_layout.tsx`

### LICENSE
- Purpose: Legal license file covering the repository source code.
- How it works: Specifies the terms under which this project code may be used or distributed.
- Uses: None
- Used by: Repository consumers and legal checks

### metro.config.js
- Purpose: Metro bundler configuration for Expo and NativeWind.
- How it works: Obtains default Metro configuration from `expo/metro-config` and wraps it with `withNativeWind` specifying `./global.css` as the styling input.
- Uses: `expo/metro-config`, `nativewind/metro`
- Used by: Expo Metro bundler

### nativewind-env.d.ts
- Purpose: TypeScript declaration file providing type support for NativeWind styling attributes.
- How it works: Adds triple-slash reference to `nativewind/types` to ensure `className` props are recognized on React Native components.
- Uses: `nativewind/types`
- Used by: TypeScript compiler via `tsconfig.json`

### package.json
- Purpose: Defines project metadata, npm scripts, and dependencies.
- How it works: Lists all installed dependencies (Expo 58, React 19, React Native 0.88, NativeWind 4, `@codsod/react-native-otp-input`, `prop-types`, etc.) and exposes scripts (`start`, `android`, `ios`, `web`, `lint`).
- Uses: npm
- Used by: npm CLI, Expo CLI

### README.md
- Purpose: Starter project overview and developer onboarding documentation.
- How it works: Provides standard instructions for running Expo CLI, testing in emulators/simulators, and helpful links.
- Uses: None
- Used by: Developers onboarding into the repo

### tailwind.config.js
- Purpose: Tailwind CSS configuration file specifying content paths and custom themes.
- How it works: Scans `./src/**/*.{js,jsx,ts,tsx}` for class names, loads `nativewind/preset`, and extends colors with custom WhatsApp branding tokens (greens, teals, dark mode background).
- Uses: `nativewind/preset`
- Used by: NativeWind / Tailwind CSS compiler

### tsconfig.json
- Purpose: TypeScript compiler configuration.
- How it works: Extends `expo/tsconfig.base`, enables strict mode, and configures path aliases `@/*` and `@/assets/*` pointing into `./src`.
- Uses: `expo/tsconfig.base`
- Used by: TypeScript compiler and IDEs

## src/app

### src/app/_layout.tsx
- Purpose: Root layout component that controls initial splash delay and top-level redirection.
- How it works: Prevents auto-hiding of the native splash screen on load, hides it in `useEffect`, and displays `<SplashScreen />` for 2500ms. Configures root Stack with `animation: 'none'` (delegating navigation transitions to inner group stacks) and redirects unauthenticated users directly to `/(auth)`.
- Uses: `expo-router`, `expo-splash-screen`, `@/components/SplashScreen`, `../../global.css`
- Used by: Expo Router root engine
- Gotchas: `isLogin` is currently a hardcoded `false` state.

---

## src/app/(auth)

### src/app/(auth)/_layout.tsx
- Purpose: Auth group stack navigator configuration with custom transitions.
- How it works: Renders an Expo Router `<Stack>` with `headerShown: false`, `animation: 'slide_from_right'`, `animationDuration: 220`, `gestureEnabled: true`, `gestureDirection: 'horizontal'`, `animationMatchesGesture: true`, and `fullScreenGestureEnabled: true`. Defines explicit `slide_from_right` transitions across screens (`index`, `terms_agree`, `login`, `verify_otp`).
- Uses: `expo-router`, `react`
- Used by: Expo Router when navigating within the `(auth)` group

### src/app/(auth)/index.tsx
- Purpose: Root route entry point for the `(auth)` group.
- How it works: Directly exports `TermsAgree` from `./terms_agree`, serving as the true initial screen (index 0) of the Auth stack without breaking native stack pop/reverse transitions with runtime redirection.
- Uses: `src/app/(auth)/terms_agree`
- Used by: Expo Router when accessing `/(auth)`

### src/app/(auth)/login.tsx
- Purpose: Screen component for user phone number entry and authentication.
- How it works: Presents country dropdown with WhatsApp green underline, an interactive back arrow `←` (calling `router.back()` with fallback to `/(auth)`), and dual inputs for calling code and local phone number. Synchronizes code input with country selection. Validates input and triggers a confirmation alert before routing to `verify_otp.tsx`.
- Uses: `react-native`, `react-native-safe-area-context`, `expo-status-bar`, `expo-router`, `@/constants/countries`, `@/components/molecules/CountryPickerModal`, `@/components/atoms/Button`
- Used by: `src/app/(auth)/_layout.tsx`, navigated to from `terms_agree.tsx`

### src/app/(auth)/terms_agree.tsx
- Purpose: WhatsApp terms of service and welcome screen.
- How it works: Displays welcome headline, illustration image, legal agreement disclaimer with links to WhatsApp privacy policy and terms of service, and an "Agree and continue" action button that pushes `/(auth)/login`.
- Uses: `react-native`, `expo-status-bar`, `expo-router`, `@/constants/imagePath`, `@/components/atoms/Button`
- Used by: `src/app/(auth)/_layout.tsx`

### src/app/(auth)/verify_otp.tsx
- Purpose: Screen component for entering and verifying OTP codes using `@codsod/react-native-otp-input`.
- How it works: Renders header with back arrow `←`, masked phone message (`Code has been send to ...`), 4-box OTP input with rounded styling and auto-focus, dynamic 56s resend countdown timer with clickable resend trigger, error badge for invalid codes (e.g. `7387` -> `Invalid password`), full-width Verify button, and a full-screen dimmed loading spinner modal that simulates verification before routing to `/(main)`.
- Uses: `@codsod/react-native-otp-input`, `react-native`, `react-native-safe-area-context`, `expo-status-bar`, `expo-router`, `react`
- Used by: `src/app/(auth)/_layout.tsx`

## src/components/molecules

### src/components/molecules/CountryPickerModal.tsx
- Purpose: Searchable modal dialog for selecting a country and international dial code.
- How it works: Opens a full-screen modal with a search input filtering country names, dial codes, and ISO codes. Renders a `FlatList` displaying flag emojis, names, and dial codes, calling `onSelect` and closing on item tap.
- Uses: `react`, `react-native`, `react-native-safe-area-context`, `expo-status-bar`, `@/constants/countries`
- Used by: `src/app/(auth)/login.tsx`

## src/constants

### src/constants/countries.ts
- Purpose: Country calling code metadata dataset and default country configuration.
- How it works: Exports `COUNTRIES` array containing country names, 2-letter ISO codes, dial codes, and flag emojis, as well as `DEFAULT_COUNTRY` (India).
- Uses: None
- Used by: `src/app/(auth)/login.tsx`, `src/components/molecules/CountryPickerModal.tsx`

### src/constants/imagePath.ts
- Purpose: Central dictionary exporting image assets.
- How it works: Requires and exports image references for `logo`, `welcome`, and `welcome_dark`.
- Uses: Image assets in `src/assets/images/`
- Used by: `src/components/SplashScreen.tsx`, `src/app/(auth)/terms_agree.tsx`
